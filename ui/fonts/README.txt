Load fonts.css and use font-family: 'Inter', sans-serif.
Normal variable weights: 100–900. font-optical-sizing: auto is supported.
The font is local: displaying the app does not request Google Fonts or another CDN.

The actual WOFF2 cmap was checked for 203 code points, including Vietnamese
uppercase/lowercase letters, decomposed accent marks, digits, and calculation
symbols. Every tested code point maps to a nonzero glyph.

Reference research: Buffer's public marketing site declares Figtree for body
text, Stolzl for headings, and Inter for its in-app Insights illustrations.
GD Toolkit uses the officially licensed Inter asset above, not font files copied
from Buffer. Inter supplies consistent Vietnamese typography throughout the UI.
